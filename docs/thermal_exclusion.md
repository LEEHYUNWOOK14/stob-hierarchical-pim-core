# 열 분석 제외 범위

이 저장소는 열 분석 구현 코드와 생성된 열 분석 산출물을 제외합니다.
구체적으로 `design/thermal/`, `hardware_cost/thermal/`,
`reports/r16_thermal/`, `output/hbm2_thermal/` 및 HotSpot/3D-ICE 통합 코드를
포함하지 않습니다.

포함된 R16 보고서는 provenance와 주장 범위를 기록한 snapshot입니다. 이
배포 범위 밖의 내용을 설명하기 위해 열 또는 전력 분석을 언급할 수 있지만,
그 언급이 해당 구현이나 결과를 이 저장소에서 재배포한다는 뜻은 아닙니다.
