# Thermal-analysis exclusion

This repository excludes thermal-analysis implementation and generated thermal
artifacts. In particular, it does not contain `design/thermal/`,
`hardware_cost/thermal/`, `reports/r16_thermal/`, `output/hbm2_thermal/`, or
HotSpot/3D-ICE integration code.

The included R16 report is a provenance and claim-boundary snapshot. It may
mention thermal or power analysis to document what is outside this release;
those mentions do not mean that the corresponding implementation or results
are redistributed here.
