# Third-party notices

The system-level simulator used during development was based on Samsung
Electronics SAIT PIMSimulator, which is derived from DRAMSim2.

The Samsung PIMSimulator source, modified simulator source, simulator binaries,
and DRAMSim2 library binaries are not redistributed in this repository.

- Samsung SAIT PIMSimulator: https://github.com/SAITPublic/PIMSimulator
- DRAMSim2: https://github.com/umd-memsys/DRAMSim2

The original project retains the applicable `LICENSE-PIMSimulator` and
`LICENSE-DRAMSIM2` files. This repository contains only the selected RTL,
verification, independent utilities, documentation, and evidence listed in
`source_map.md`.

External model and workload references are cited in the report. External paper
PDF/HTML files and model checkpoints are not copied into this repository.
